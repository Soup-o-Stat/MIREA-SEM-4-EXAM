## 1. The History of Computers (История компьютеров)

Компьютеры появились не сразу. Всё началось с простых счётных инструментов, потом механических устройств, потом электронных, и так до современных компьютеров с искусственным интеллектом.

### Этапы развития:

1. **Sticks and stones (палочки и камушки)**
   Самые первые счётные средства. Люди просто отмечали количество.

2. **Abacus (абак, \~1300 до н.э., Китай)**
   Первая счётная машина. Умеет: addition (сложение), subtraction (вычитание), multiplication (умножение), division (деление).

3. **Pascaline (1642–1644, Блез Паскаль)**
   Первое **mechanical adding machine** (механическое устройство для сложения).
   Было похоже на деревянную коробку с шестерёнками.

4. **Analytical Engine (1830-е, Чарльз Бэббидж)**
   Считается «father of the computer» (отец компьютера).
   В его проекте были:

   * ALU (Arithmetic Logic Unit — арифметико-логическое устройство),
   * Control Unit (устройство управления),
   * Memory (память),
   * Input/Output system (система ввода/вывода).
     Это базовые части любого компьютера.

5. **Konrad Zuse (1936, Германия)**
   Первая программируемая машина — Z1 (потом Z2, Z3).

### Generations of Computers (Поколения компьютеров):

1. **First generation (первая генерация)**

   * Vacuum tubes (вакуумные лампы).
   * ENIAC (Electronic Numerical Integrator and Calculator).
   * Огромные, медленные, много энергии, много проблем.

2. **Second generation**

   * Transistors (транзисторы).
   * Компьютеры стали меньше и быстрее.

3. **Third generation**

   * Integrated Circuits (интегральные схемы, маленькие микросхемы с тысячами транзисторов).
   * Скорость увеличилась: microseconds → nanoseconds.
   * Появились mouse (мышь) и keyboard (клавиатура).

4. **Fourth generation (1972)**

   * Microprocessors (микропроцессоры).
   * VLSI (Very Large Scale Integration — очень крупная интеграция).
   * Всё в одном чипе (silicon chip — кремниевый чип).

5. **Fifth generation (1980-е – сегодня)**

   * Artificial Intelligence (AI — искусственный интеллект).
   * Parallel processing (параллельные вычисления).
   * FGCS (Fifth Generation Computer System, Япония, 1982).

## 2. Types of Computers and their Use

Компьютеры бывают разные: от супердорогих и мощных машин до маленьких планшетов. Классификация — по размеру, мощности и назначению.

### Виды компьютеров:

1. **Servers (серверы)**

   * Обслуживают другие компьютеры (clients) в сети.
   * Используются в: finance (финансы), healthcare (медицина), e-commerce (интернет-магазины), government (госструктуры).
   * Пример: серверы Google, которые хранят миллионы сайтов.

2. **Mainframe computers (мэйнфреймы)**

   * Очень мощные машины.
   * Умеют работать с огромными объёмами данных и одновременно обслуживать сотни пользователей.
   * Особенности: high speed (высокая скорость), huge memory (большая память), reliability (надёжность).
   * Где применяют: банки, авиакомпании, госучреждения.

3. **Supercomputers (суперкомпьютеры)**

   * Ещё мощнее, чем мэйнфреймы.
   * Предназначены для одной **очень сложной задачи**.
   * Speed: billions of operations per second (миллиарды операций в секунду).
   * Использование: weather forecasting (прогноз погоды), nuclear research (ядерные исследования), oil and gas exploration (добыча нефти и газа), quantum mechanics.
   * Первый суперкомпьютер — создан Roger Cray (1976).

4. **Desktop PC (настольный компьютер)**

   * General-purpose computer (универсальный компьютер).
   * Использование: документы, презентации, фильмы, интернет.
   * Основные части: CPU (процессор), memory (память), input/output (ввод/вывод).

5. **Laptop (ноутбук)**

   * Portable (портативный), можно держать на коленях.
   * Встроенные экран, клавиатура, touchpad (сенсорная панель).
   * Работает от батареи.
   * Использование: учёба, работа, игры, видео-монтаж.

6. **Tablet (планшет)**

   * Wireless touchscreen PC (беспроводной ПК с сенсорным экраном).
   * Меньше и легче ноутбука.
   * Минусы: меньше памяти, слабее по мощности, нет вентилятора (может перегреваться).
   * Использование: чтение книг, просмотр фильмов, фото, рисование стилусом.

## 3. Computer Hardware

Компьютер состоит из **hardware** (железо) и **software** (программы). Hardware — это всё, что можно потрогать (процессор, память, клавиатура), а software — инструкции, что делать.

### Основные части:

1. **CPU (Central Processing Unit — центральный процессор)**

   * «Мозг» компьютера.
   * Состоит из:

     * **Control Unit (CU)** — управляет работой всех компонентов.
     * **ALU (Arithmetic Logic Unit)** — выполняет математику (+, -, AND, OR, NOT).
     * **Registers (регистры)** — сверхбыстрая память для временного хранения данных.

       * **PC (Program Counter)** — указывает на следующую инструкцию.
       * **IR (Instruction Register)** — хранит текущую инструкцию.
   * Работает под управлением **system clock (системные часы)**. Clock speed измеряется в **GHz (gigahertz)**.

2. **Memory (память)**

   * **RAM (Random Access Memory)** — оперативка, временная память, данные стираются при выключении.
   * **ROM (Read Only Memory)** — постоянная память, хранит BIOS (Basic Input/Output System).

3. **Peripherals (периферия)**

   * Устройства, подключаемые к компьютеру.
   * Input devices (ввод): keyboard, mouse.
   * Output devices (вывод): monitor, printer.
   * Storage devices (хранение):

     * Magnetic (магнитные) — HDD, floppy disk.
     * Optical (оптические) — CD, DVD, Blu-ray.
     * Flash memory (флэш) — USB stick, SD card.

4. **Motherboard (материнская плата)**

   * Главная плата, куда подключается всё остальное: процессор, память, карты расширения.
   * Связь обеспечивают **buses (шины)**.

     * Bus width (ширина шины) — сколько данных может передаваться за раз.
     * Example: Front Side Bus — соединяет CPU с памятью.

## 4. Primary Storage

**Primary storage** (первичная память) — это внутренняя память, к которой процессор (CPU) может обращаться напрямую. Она бывает **volatile (энергозависимая)** и **non-volatile (энергонезависимая)**.

### Основные виды:

1. **ROM (Read Only Memory — постоянная память, «только чтение»)**

   * Non-volatile (не стирается при выключении).
   * Хранит инструкции для запуска компьютера (BIOS).
   * CPU читает данные из ROM → загружает их в RAM → и только потом использует.
   * Применение: BIOS, игровые картриджи (Nintendo, Sega).
   * Виды ROM:

     * **MROM (Masked ROM)** — записывается на заводе, изменить нельзя.
     * **PROM (Programmable ROM)** — можно записать один раз.
     * **EPROM (Erasable PROM)** — можно стереть ультрафиолетом и перезаписать.
     * **EEPROM (Electrically Erasable PROM)** — можно стирать электрически, до \~10 000 раз.
     * **Flash ROM** — современный вариант EEPROM, очень быстрый, выдерживает >1 000 000 циклов перезаписи.

2. **RAM (Random Access Memory — оперативная память)**

   * Volatile (данные исчезают при выключении).
   * Хранит временные данные и программы, которые сейчас выполняются.
   * Виды RAM:

     * **SRAM (Static RAM)** — быстрая, дорогая, хранит данные без обновления (используется для кэша).
     * **DRAM (Dynamic RAM)** — дешёвая, хранит данные в конденсаторах, нужно постоянно обновлять (используется как основная память).

3. **Cache (кэш-память)**

   * Очень быстрая память между CPU и RAM.
   * Сохраняет часто используемые данные.
   * Виды записи:

     * **Write-through** — данные пишутся сразу и в кэш, и в RAM (надёжно, но медленно).
     * **Write-back** — сначала в кэш, а потом в RAM (быстрее, но сложнее в управлении).

## 5. Secondary Storage

**Secondary storage** (вторичная память) — это долгосрочное хранение данных. В отличие от **primary storage**, она **non-volatile** (данные не стираются при выключении компьютера).

### Основные виды:

1. **Magnetic storage (магнитные устройства)**

   * Хранят данные за счёт намагничивания частиц.
   * Примеры:

     * **HDD (Hard Disk Drive — жёсткий диск)**

       * Состоит из вращающихся пластин (platters).
       * Чтение/запись — с помощью магнитной головки.
       * Метрики:

         * **Seek time** (время доступа) — 7–14 ms (миллисекунд).
         * **Transfer rate** (скорость передачи) — MB/s.
     * Floppy disk (дискета).
     * Magnetic tape (магнитная лента).

2. **SSD (Solid-State Drive — твердотельный накопитель)**

   * Использует **flash memory chips** (микросхемы флеш-памяти).
   * Нет движущихся частей (в отличие от HDD).
   * Быстрее и надёжнее, менее чувствителен к ударам.
   * Дороже, чем HDD.

3. **Optical storage (оптические устройства)**

   * Используют **laser beam (лазерный луч)** для записи/чтения.
   * Хранение данных в виде «pits» (ямок) на диске.
   * Примеры: **CD, DVD, Blu-ray**.
   * * Долговечные.
   * – Медленные, маленький объём.

4. **Cloud storage (облачное хранение)**

   * Данные сохраняются на удалённых серверах.
   * Доступ через Internet.
   * Пример: Google Drive, Dropbox.

## 6. Software (Программное обеспечение)

**Software** = набор инструкций, которые говорят компьютеру, что делать. Делится на **system software** и **application software**.

### Виды Software:

1. **System software (системное ПО)**

   * Управляет компьютером.
   * Примеры:

     * **Operating system (ОС)** — Windows, Linux, macOS.
     * **Device drivers (драйверы)** — программы для работы оборудования.
     * **Firmware (прошивка)** — встроенное ПО (например, в телефоне или роутере).

2. **Application software (прикладное ПО)**

   * То, чем мы пользуемся напрямую.
   * Примеры:

     * Word processors (текстовые редакторы, напр. MS Word).
     * Spreadsheets (электронные таблицы, напр. Excel).
     * Web browsers (браузеры, напр. Chrome).
     * Database software (управление БД, напр. MySQL).

### Операционные системы (Operating Systems, ОС):

* **Функции**:

  1. Manage resources (управляют ресурсами: CPU, память, диски).
  2. Provide interface (дают интерфейс пользователю).
  3. Run applications (запускают программы).

* **По типу работы**:

  * Single-tasking (только одна программа).
  * Multi-tasking (несколько программ).

    * Preemptive multitasking — ОС сама распределяет ресурсы.
    * Cooperative multitasking — программы сами «делятся» временем.

* **По пользователям**:

  * Single-user (один пользователь).
  * Multi-user (несколько пользователей).

* **По интерфейсу**:

  * CLI (Command Line Interface) — работа через команды (пример: Linux bash).
  * GUI (Graphical User Interface) — графика, мышь, окна, меню (Windows, macOS).

* **Open-source** vs **Proprietary**:

  * Open-source (открытый код) — Linux.
  * Proprietary (закрытый код) — Windows, macOS.

## 7. Networks (Сети)

**Network** = несколько компьютеров + устройства, соединённые для обмена данными.

### По размеру:

* **LAN (Local Area Network)** — локальная сеть (офис, дом).
* **MAN (Metropolitan Area Network)** — сеть города.
* **WAN (Wide Area Network)** — огромная сеть (страна, континент).
* Самая большая WAN = **Internet**.

### По архитектуре:

* **Client-server**: один сервер, остальные клиенты.
* **Peer-to-peer**: все равны, каждый может быть клиентом и сервером (пример: торрент).

### Топологии (как соединены компьютеры):

* **Star (звезда)** — все подключены к центральному узлу.
* **Bus (шина)** — один общий кабель.
* **Ring (кольцо)** — соединены по кругу.
* **Tree (дерево)** — иерархия, комбинация звезды и шины.
* **Mesh (ячеистая)** — каждый с каждым.
* **Hybrid (гибрид)** — смешанная.

### По среде передачи:

* **Wired (проводные сети)**:

  * Twisted-pair (витая пара), coaxial cable (коаксиал), fiber optic (оптика).
* **Wireless (беспроводные)**:

  * Wi-Fi (радиоволны).

### Network devices (сетевые устройства):

* **Modem** — подключает к Интернету.
* **Router (роутер)** — распределяет Интернет по сети.
* **Switch (коммутатор)** — соединяет устройства в локальной сети.
* **Hub (концентратор)** — примитивное устройство, отправляет сигнал всем.
* **Bridge (мост)** — соединяет разные сети.
* **Gateway (шлюз)** — выход в другие сети/Интернет.

## 8. The Internet

Интернет — это глобальная сеть. Подключение может быть разным: через телефонные линии, кабели, оптоволокно, Wi-Fi, спутники и мобильные сети.

### Виды подключения:

1. **DSL (Digital Subscriber Line)** — цифровая абонентская линия

   * Использует обычные телефонные линии (copper twisted-pair).
   * Технология **ADSL (Asymmetric DSL)** — скорость скачивания выше, чем загрузки.

2. **Cable Internet (кабельный Интернет)**

   * Использует инфраструктуру кабельного телевидения.
   * Через coaxial cable (коаксиальный кабель).
   * Минус: скорость может падать при нагрузке (много пользователей одновременно).

3. **Fiber-optic Internet (оптоволоконный Интернет)**

   * Передаёт данные с помощью света.
   * Очень высокая скорость, меньше искажений.

4. **Wireless Internet (беспроводной)**

   * **Wi-Fi** — радиоволны, для локальной сети.
   * **Satellite Internet (спутниковый)** — через спутник на орбите (минус: задержка).
   * **Cellular network (сотовая сеть)** — Интернет через вышки мобильного оператора (3G, 4G, 5G).

### Технологии передачи:

* **Circuit switching (коммутация каналов)**

  * Устанавливается выделенный канал связи.
  * Минус: если канал простаивает → теряется пропускная способность.
  * Использовался в телефонных сетях.

* **Packet switching (пакетная коммутация)**

  * Данные делятся на пакеты.
  * Каждый пакет может идти своим маршрутом.
  * Потом собираются в правильном порядке.
  * Более эффективно → используется в Интернете.

* **TCP/IP (Transmission Control Protocol / Internet Protocol)**

  * Набор стандартных протоколов для Интернета.
  * TCP — отвечает за надёжную доставку данных.
  * IP — за адресацию и маршрутизацию.
  * 4 уровня (или 5): физический, канальный, сетевой, транспортный, прикладной.

## 9. Search Engines (Поисковые системы)

### Кратко:

Search engine (поисковая система) = программа, которая ищет информацию по запросу пользователя.

### Типы:

1. **Crawler-based search engines (поисковики с «роботами»)**

   * Примеры: Google, Yahoo.
   * Работают автоматически в 3 шага:

     1. **Crawling** — специальные боты (spiders) обходят сайты.
     2. **Indexing** — система выделяет ключевые слова (keywords).
     3. **Ranking** — поисковик решает, какой сайт наиболее релевантный запросу.

2. **Human-powered directories (человеческие каталоги)**

   * Сайты добавляют вручную редакторы.
   * Примеры: Yahoo! Directory, Open Directory.
   * Раньше были популярны, сейчас почти не используются.

3. **Meta-search engines (метапоисковики)**

   * Примеры: MetaCrawler, Dogpile.
   * У них нет собственной базы.
   * Они отправляют запрос в другие поисковики и собирают результаты в один список.

## 10. Programming Languages (Языки программирования)

Программа = набор инструкций для компьютера. Компьютер напрямую понимает только **machine code (машинный код, 0 и 1)**. Чтобы писать удобнее, люди придумали языки.

### Виды языков:

1. **Low-level languages (низкоуровневые языки)**

   * **Machine code** — только 0 и 1.
   * **Assembly language** — команды типа `ADD`, `SUB`, `MPY`.
   * Нужен **assembler (ассемблер)** для перевода в машинный код.

2. **High-level languages (высокоуровневые)**

   * Ближе к английскому языку.
   * Портативные (работают на разных компьютерах).
   * Примеры:

     * **FORTRAN** (IBM, 1950-е) — для науки и инженерии.
     * **C** — системное ПО, графика.
     * **Java** — интернет, веб-приложения, объектно-ориентированное программирование (OOP).
     * **Python** (1989) — веб, AI, анализ данных.

### Перевод программ:

* **Compiler (компилятор)** — переводит весь код сразу в машинный.
* **Interpreter (интерпретатор)** — переводит построчно при запуске.

## 11. Basics of Web Design (Основы веб-дизайна)

Web design = создание и оформление сайтов. Первая страница была сделана **Tim Berners-Lee (Тим Бернерс-Ли)** в 1991.

### Основные технологии:

1. **HTML (HyperText Markup Language — язык гипертекстовой разметки)**

   * Структура страницы.
   * Работает с тегами: `<p>`, `<img>`, `<a>`.
   * Управляет содержимым (текст, таблицы, ссылки).

2. **CSS (Cascading Style Sheets — каскадные таблицы стилей)**

   * Отвечает за внешний вид: цвета, шрифты, расположение.
   * Можно менять стиль сразу у всего сайта.

3. **JavaScript (JS)**

   * Делает сайт «живым».
   * Добавляет анимацию, кликабельные кнопки, меню.
   * Ключевая технология вместе с HTML и CSS.

## 12. Security and Privacy on the Internet (Безопасность и приватность в Интернете)

Интернет даёт доступ к информации, но создаёт риски: вирусы, взломы, утечки данных. Нужно защищаться.

### Основные угрозы:

* **Hackers (хакеры)** — взламывают системы.
* **Malware (вредоносное ПО)**:

  * **Virus** — заражает файлы, активируется при запуске.
  * **Worm** — сам распространяется по сети.
  * **Trojan horse (троян)** — маскируется под полезную программу.
  * **Spyware** — шпионит, собирает данные.
  * **Adware** — показывает рекламу (pop-ups).

### Методы защиты:

1. **Passwords** — надёжные пароли.
2. **Firewalls (фаерволы)** — фильтруют входящие данные.
3. **Encryption (шифрование)** — превращает данные в код (ciphertext), чтобы без ключа никто не прочитал.
4. **Digital certificates** — цифровые «паспорта» для сайтов и пользователей.
5. **Antivirus software** — обнаруживает и удаляет вирусы.
6. **Cookies** — маленькие файлы, сохраняют информацию о пользователе (можно удалять).

## 13. Data Security (Защита данных)

Data security = защита информации от потери, кражи, повреждения.

### Методы защиты:

1. **Firewalls**

   * Фильтруют пакеты данных.
   * Можно заблокировать по адресу, слову или программе.

2. **Backups (резервные копии)**

   * **Full backup** — копируется всё.
   * **Differential backup** — копируются изменения после последнего полного бэкапа.
   * **Incremental backup** — копируются изменения после последнего любого бэкапа.

3. **Power protection**

   * UPS (Uninterruptible Power Supply — бесперебойник).
   * Surge protectors (защита от перепадов напряжения).

4. **Passwords (пароли)** — сложные и надёжные.

5. **Encryption (шифрование)**

   * Plaintext (обычный текст) → Ciphertext (зашифрованный текст).
   * Используется ключ для расшифровки (decryption key).

6. **Biometric security**

   * Отпечатки пальцев, скан лица.

7. **Antivirus software**

   * **Signature-based scanning** — ищет «отпечаток» вируса.
   * **Heuristic scanning** — ищет подозрительное поведение.

## 14. IT Trends (Тренды в ИТ)

### Кратко:

Информационные технологии постоянно развиваются. Основные тренды последних лет:

### Главные направления:

1. **Cloud computing (облачные вычисления)**

   * Данные и приложения хранятся на удалённых серверах.
   * Пользователь получает доступ через Интернет.
   * Примеры: Google Drive, Dropbox, AWS (Amazon Web Services).

2. **Big Data (большие данные)**

   * Огромные объёмы информации, которые нельзя обработать обычными методами.
   * Используются в бизнесе, медицине, науке.
   * Технологии: Hadoop, Spark.

3. **Artificial Intelligence (AI, искусственный интеллект)**

   * Компьютеры, которые учатся и принимают решения.
   * Области: чат-боты, переводчики, распознавание лиц.

4. **Machine Learning (ML, машинное обучение)**

   * Подраздел AI. Компьютер учится на данных, сам улучшает алгоритмы.
   * Примеры: рекомендации YouTube, Netflix.

5. **IoT (Internet of Things — интернет вещей)**

   * Устройства, подключённые к Интернету: умные часы, холодильники, датчики.

6. **Blockchain (блокчейн)**

   * Технология распределённой базы данных.
   * Используется в криптовалютах (Bitcoin, Ethereum).

7. **Cybersecurity (кибербезопасность)**

   * Всё больше угроз → растёт значение защиты данных.

## 15. IT Professions (ИТ-профессии)

ИТ-сфера очень разнообразна. Существуют десятки профессий, каждая со своей ролью.

### Основные профессии:

1. **Software developer (разработчик ПО)**

   * Пишет программы.
   * Знает языки программирования.

2. **Web developer (веб-разработчик)**

   * Делает сайты.
   * Front-end (видимая часть) — HTML, CSS, JavaScript.
   * Back-end (серверная часть) — базы данных, Python, PHP, Java.

3. **System administrator (системный администратор)**

   * Настраивает серверы, сети, компьютеры.
   * Следит за безопасностью.

4. **Database administrator (DBA, администратор БД)**

   * Управляет базами данных.
   * Следит за хранением и безопасностью информации.

5. **Network engineer (сетевой инженер)**

   * Проектирует и поддерживает сети.
   * Работает с роутерами, протоколами, топологиями.

6. **Data analyst / Data scientist**

   * Анализирует данные, делает выводы.
   * Использует Big Data, ML, статистику.

7. **Cybersecurity specialist (специалист по кибербезопасности)**

   * Защищает системы от атак.
   * Работает с шифрованием, брандмауэрами, антивирусами.

8. **AI / ML engineer**

   * Создаёт системы искусственного интеллекта.
